# Python API

Python binding for `sqlce` over [libsqlce](cpp.md) (pybind11). Read-only access to `.sdf` files (SQL Server Compact). Full signature documentation with the semantics of each method is available in the native module docstrings: [_sqlce_native.pyi](../../python/sqlce/_sqlce_native.pyi).

## Installation

```text
pip install sqlce
```

## Example

```python
from sqlce import SqlceDatabase

db = SqlceDatabase("file.sdf")
db = SqlceDatabase("file.sdf", "password")

for name in db.list_tables():
    print(name)

for col in db.table_schema("MyTable"):
    print(col.ordinal, col.name, col.type_name, col.declared_size, col.precision, col.scale)

rows = db.read_table("MyTable")
for row in db.iterate_table("MyTable"):
    print(row)
```

## SqlceDatabase

Read-only access to an `.sdf` file; there are no write methods. Opening immediately parses the system catalog and resolves the data pages of every table; rows are decoded lazily when accessed. The logical page map and catalog are read once and cached for the entire lifetime of the object.

| Method                                                                   | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Complexity / Features                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|--------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `__init__(path)`                                                         | Open an unencrypted file.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | `InvalidPasswordError` if the file is password-protected (this overload does not accept a password). O(P/1527 + K + T), where P is the number of pages in the file (the number of Map B pages grows with P because each Map B page indexes a range of 1527 logical identifiers, and every file page has a logical identifier, including table data pages), K is the number of heap pages in the system catalog, and T is the number of tables (one root page per table). |
| `__init__(path, password)`                                               | Open a password-protected file (no more than 40 bytes after UTF-16LE encoding). The password is checked sequentially using the page 0 verifier for all 4 algorithms (`TRIPLE_DES_SHA1`, `AES128_SHA1`, `AES128_SHA256`, `AES256_SHA512`) until a match is found. The file itself stores the encryption algorithm, available through `GetEncryptionMode`, but the constructor does not rely on it. The result is available through `resolved_encryption_mode()` and may theoretically differ from the mode declared in the file. | Algorithm resolution: up to 4 attempts, each consisting of password hashing for key derivation followed by decryption of one verifier block on page 0. After that, catalog parsing is the same as in the passwordless constructor: O(P/1527 + K + T) (see the description of that overload for details).                                                                                                                                                                 |
| `list_tables() -> List[str]`                                             | Names of all user tables in lexicographical order.                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | O(T), without accessing the file.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `table_schema(table_name) -> List[ColumnSchema]`                         | Column descriptions in ascending ordinal order.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | O(C), without reading pages. `IndexError` if no table with the specified name exists.                                                                                                                                                                                                                                                                                                                                                                                    |
| `read_table(table_name) -> List[Row]`                                    | Reads and decodes all table rows at once into a list; equivalent to `list(self.iterate_table(table_name))`. LOB columns (NText, Image) are not loaded into memory; the cell contains a `LazyLob` object.                                                                                                                                                                                                                                                                                                                        | O(R*C) in time and memory, with the entire result held in memory simultaneously.                                                                                                                                                                                                                                                                                                                                                                                         |
| `iterate_table(table_name) -> TableRowIterator`                          | Lazy row-by-row iterator: rows are read and decoded one at a time as the iterator is consumed, without materializing the entire table in memory.                                                                                                                                                                                                                                                                                                                                                                                | `IndexError` is raised immediately when the method is called; `InvalidSdfError` is raised lazily during iteration.                                                                                                                                                                                                                                                                                                                                                       |
| `row_count(table_name) -> int`                                           | If the table root page contains a recognizable cardinality field, the value is read directly from that field without scanning rows; otherwise, a full pass over `iterate_table` is performed, counting rows without decoding column values.                                                                                                                                                                                                                                                                                     | O(1) if the cardinality field is recognized; O(R) otherwise. The field is read from the file on every call and is not cached.                                                                                                                                                                                                                                                                                                                                            |
| `get_encryption_mode() -> EncryptionMode`                                | The mode declared on page 0, regardless of whether a password was provided or matched.                                                                                                                                                                                                                                                                                                                                                                                                                                          | O(1), computed during opening.                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `get_encryption_mode_from_file(path) -> EncryptionMode` (staticmethod)   | The same mode without creating a `SqlceDatabase` object and without parsing the catalog or page map.                                                                                                                                                                                                                                                                                                                                                                                                                            | Separate file descriptor; only page 0 is read, then the descriptor is closed.                                                                                                                                                                                                                                                                                                                                                                                            |
| `resolved_encryption_mode() -> EncryptionMode`                           | The algorithm actually confirmed by the password during opening.                                                                                                                                                                                                                                                                                                                                                                                                                                                                | `NONE` for an unencrypted file.                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `get_format_version() -> FormatVersion`                                  | Format version at a fixed offset on page 0.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | O(1), computed by the constructor.                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `get_format_version_from_file(path) -> FormatVersion` (staticmethod)     | The same field without creating a `SqlceDatabase`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Only page 0 is read.                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `export_decrypted() -> bytes`                                            | Full file contents with encryption removed. Each page is decrypted; on page 0, the encryption mode, verifier, key-param, provider-info, and “was encrypted” flag fields are zeroed, and the page 0 checksum is recalculated. If `resolved_encryption_mode() == NONE`, pages are returned unchanged. Requires the file to have already been successfully opened by the constructor with the correct password.                                                                                                                    | O(P) in the number of pages; the entire result is held in memory simultaneously.                                                                                                                                                                                                                                                                                                                                                                                         |
| `verify_password(path, password) -> bool` (staticmethod)                 | Checks the password against all 4 algorithms without opening the file as a database; stops at the first match. If none match, returns `False` without raising an exception.                                                                                                                                                                                                                                                                                                                                                     | Only page 0 is read from disk, once, regardless of the number of attempts.                                                                                                                                                                                                                                                                                                                                                                                               |
| `verify_password_with_mode(path, password, mode) -> bool` (staticmethod) | Checks one specific algorithm.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | `mode=EncryptionMode.NONE` is invalid and raises `UnsupportedEncryptionModeError`.                                                                                                                                                                                                                                                                                                                                                                                       |

## ColumnSchema

An immutable snapshot at the time `table_schema()` is called.

| Property        | Description                                                                                                                                                                                                    |
|-----------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `ordinal`       | Column position in the table, starting at 1, in ascending catalog ordinal order.                                                                                                                               |
| `name`          | Column name.                                                                                                                                                                                                   |
| `type_name`     | `"int"`, `"nvarchar"`, `"ntext"`, `"image"`, `"uniqueidentifier"`, etc.                                                                                                                                        |
| `declared_size` | `Optional[int]`: for NVarChar/NChar, the number of characters; for Binary/VarBinary, the number of bytes; for Image, the constant `0x3FFFFFFF`; for NText, the constant `0x1FFFFFFF`; for other types, `None`. |
| `precision`     | `Optional[int]`: fixed values by type (Bit=1/0, TinyInt=3, SmallInt=5, Int=10, BigInt=19, Real=24, Float=53, Money=19/4, DateTime=23/3), or values from the catalog for Numeric; otherwise `None`.             |
| `scale`         | `Optional[int]`: fixed values by type (Bit=1/0, TinyInt=3, SmallInt=5, Int=10, BigInt=19, Real=24, Float=53, Money=19/4, DateTime=23/3), or values from the catalog for Numeric; otherwise `None`.             |

## Types

A column value (`ColumnValue`) is an ordinary Python object.

| Python Type         | SQL Server Compact Type           | Description                                                                        |
|---------------------|-----------------------------------|------------------------------------------------------------------------------------|
| `None`              | NULL                              | NULL.                                                                              |
| `int`               | TinyInt / SmallInt / Int / BigInt | Integer value.                                                                     |
| `float`             | Real / Float / Money              | Floating-point value; Money is decoded accordingly.                                |
| `bool`              | Bit                               | Boolean value.                                                                     |
| `str`               | NVarChar                          | Variable-length string; may be Latin1-compressed.                                  |
| `str`               | NChar                             | Fixed-length string, always UTF-16LE.                                              |
| `bytes`             | Binary / VarBinary / RowVersion   | Binary value.                                                                      |
| `bytes`             | Any unrecognized type             | Binary representation of the value.                                                |
| `datetime.datetime` | DateTime                          | From a day counter starting at 1900-01-01 and ticks at 1/300 second from midnight. |
| `decimal.Decimal`   | Numeric                           | From precision/scale/sign and little-endian catalog digits.                        |
| `uuid.UUID`         | UniqueIdentifier                  | 16 bytes as `bytes_le`.                                                            |
| `LazyLob`           | NText / Image                     | Not read during row decoding.                                                      |

| Row Type                       | Description                                                                    |
|--------------------------------|--------------------------------------------------------------------------------|
| `Row = Dict[str, ColumnValue]` | Ordinary dictionary; key order corresponds to increasing dense column ordinal. |

### LazyLob

A lazy reference to an LOB value (NText or Image), returned instead of the actual value when reading a row. It retains the read source (LOB chain pages), not the data.

| Method                                  | Description                                                                                                                                    | Complexity / Features                                                                                                                                                                    |
|-----------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `read() -> Union[str, bytes]`           | Reads the entire value: `str` for NText (after UTF-16LE or Latin1 decoding according to the compression flag of the value), `bytes` for Image. | O(L), where L is the value length in bytes; for non-inline values, the number of accesses to the page cache equals the number of pages in the LOB chain.                                 |
| `read_chunks() -> LazyLobChunkIterator` | Reads in chunks without decoding or assembling the result into a single string; chunks are read lazily, one per `__next__()` call.             | For non-inline values, one element per page in the LOB chain; for inline values, one element (or none for an empty value). O(L) total, O(1) per chunk, O(1) for `len()` on the iterator. |

### TableRowIterator

Returned by `iterate_table()`. Holds a reference to the `SqlceDatabase` object, so the database remains alive while the iterator exists.

| Operation / Characteristic | Description                                                                                                                                                                                                                                                                                            |
|----------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `__next__()`               | Finds and decodes the next row, starting the search from the slot immediately after the current position; scans slots on the current data page and, when exhausted, moves to the next data page of the table; a row fragmented across multiple pages is assembled through the continuation-slot chain. |
| Search complexity          | O(P) in the worst case, where P is the number of data pages not yet scanned before the next row.                                                                                                                                                                                                       |
| Amortized complexity       | O(1) amortized with densely packed rows.                                                                                                                                                                                                                                                               |
| Row decoding               | O(C) for decoding C columns of a row.                                                                                                                                                                                                                                                                  |
| Completion                 | Raises `StopIteration`.                                                                                                                                                                                                                                                                                |
| Structural error           | Raises `InvalidSdfError` if the continuation-slot chain cannot be fully resolved or exceeds the internal transition limit.                                                                                                                                                                             |

## Exceptions

| Exception                        | Base Class   | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|----------------------------------|--------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `UnsupportedEncryptionModeError` | `ValueError` | Key derivation was requested for `EncryptionMode.NONE`, which is not a key-derivation algorithm. The only public path is `verify_password_with_mode(..., mode=EncryptionMode.NONE)`.                                                                                                                                                                                                                                                                                                                                                                                                           |
| `InvalidPasswordError`           | `ValueError` | The password did not match any of the 4 algorithms (`TRIPLE_DES_SHA1`, `AES128_SHA1`, `AES128_SHA256`, `AES256_SHA512`) when opening the file, or the file is encrypted and no password was provided. After a `SqlceDatabase` object has been successfully created, this exception can no longer be raised by any of its methods: algorithm resolution and verification occur once in the constructor, and the result is cached for the object's entire lifetime. It is not raised if the password exceeds 40 bytes after UTF-16LE encoding; in that case, an ordinary `ValueError` is raised. |
| `InvalidSdfError`                | `ValueError` | The `.sdf` file is structurally invalid: shorter than one page; the logical page map (Map A / Map B) is missing or corrupted; the chain of row fragments, catalog rows, or LOB values cannot be fully resolved or exceeds the internal limit on continuation-page transitions. `str(error)` contains a textual description of the specific cause.                                                                                                                                                                                                                                              |
