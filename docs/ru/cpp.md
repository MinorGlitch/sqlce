# C++ API

Библиотека для парсинга `.sdf`-файлов (SQL Server Compact). Только чтение: `list_tables`, `table_schema`, `read_table`/`iterate_table`, `row_count`, метаданные файла, снятие шифрования.

## Сборка

| Параметр                      | Значение                                                                              |
|-------------------------------|---------------------------------------------------------------------------------------|
| Система сборки                | CMake                                                                                 |
| Стандарт                      | C++20                                                                                 |
| `SQLCE_BUILD_PYTHON_BINDINGS` | `OFF` по умолчанию; для C++ не нужна                                                  |
| Таргет                        | `libsqlce` (объектная библиотека, статическая или shared через `BUILD_SHARED_LIBS`)   |
| Бинарник                      | `sdf_dump` (`main.cpp`, дампит все `.sdf`-файлы из директории, переданной аргументом) |

## Пример

```c++
#include "sdf/application/SqlceDatabase.hpp"

sdf::application::SqlceDatabase db("file.sdf");
// или с паролем
sdf::application::SqlceDatabase db("file.sdf", "password");

for (auto& name : db.ListTables()) { ... }

auto schema = db.TableSchema("MyTable");
auto rows = db.ReadTable("MyTable");
```

## SqlceDatabase ([sdf/application/SqlceDatabase.hpp](../../core/include/sdf/application/SqlceDatabase.hpp))

Открытие файла разбирает системный каталог и резолвит страницы данных каждой таблицы немедленно; тела строк не читаются - только карта их расположения. Строки декодируются лениво, при обращении. Объект хранит карту логических страниц (Map A / Map B) и каталог однократно, на всё время жизни.

| Метод / конструктор                                   | Описание                                                                                                                                                                                                                                      | Сложность / особенности                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|-------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `SqlceDatabase(path)`                                 | Открыть незашифрованный файл.                                                                                                                                                                                                                 | Бросает `InvalidPasswordException`, если файл защищён паролем. O(P/1527 + K + T), где **P** - количество страниц в файле (количество страниц Map B растёт вместе с P, поскольку каждая страница Map B индексирует диапазон из 1527 логических идентификаторов, а каждая страница файла имеет логический идентификатор, включая страницы данных таблиц), **K** - количество heap-страниц системного каталога, а **T** - количество таблиц (по одной корневой странице на таблицу).                                                                                              |
| `SqlceDatabase(path, password)`                       | Открыть файл с паролем. Пароль проверяется по очереди с помощью verifier'а страницы 0 для всех 4 поддерживаемых алгоритмов (`TripleDesSha1`, `Aes128Sha1`, `Aes128Sha256`, `Aes256Sha512`), пока не найдено совпадение.                       | Сам файл хранит алгоритм шифрования, и он доступен через `GetEncryptionMode`, но конструктор на него не полагается. Результат доступен через `ResolvedEncryptionMode()` и теоретически может отличаться от объявленного в файле режима. Пароль - не более 40 байт после кодирования UTF-16LE. Разрешение алгоритма: до 4 попыток, каждая - деривация ключа путём хеширования пароля плюс расшифрование одного блока verifier страницы 0. После этого разбор каталога - такой же, как в конструкторе без пароля: O(P/1527 + K + T) (подробности см. в описании той перегрузки). |
| `ListTables() -> vector<string>`                      | Имена всех пользовательских таблиц в лексикографическом порядке.                                                                                                                                                                              | O(T), без обращения к файлу - список собран конструктором.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `TableSchema(name) -> vector<ColumnSchema>`           | Описания колонок в порядке возрастания ordinal.                                                                                                                                                                                               | O(C), без чтения страниц.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `IterateTable(name) -> TableRowRange`                 | Ленивый диапазон: строки декодируются по одной, без материализации таблицы целиком.                                                                                                                                                           | Возвращённый объект держит невладеющие указатели на данные `SqlceDatabase` - не должен пережить исходный объект.                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `ReadTable(name) -> vector<Row>`                      | Эквивалентно материализации `IterateTable(name)` в вектор.                                                                                                                                                                                    | O(R*C) по времени и памяти.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `RowCount(name) -> uint32_t`                          | Если корневая страница таблицы содержит распознаваемое поле кардинальности, значение читается напрямую; иначе выполняется полный проход по `IterateTable` с подсчётом строк без декодирования значений колонок.                               | O(1), без чтения строк, если поле кардинальности распознано; иначе O(R). Поле читается из файла при каждом вызове, не кешируется.                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `GetEncryptionMode() -> EncryptionMode`               | Режим, объявленный на странице 0, независимо от того, был ли дан и подошёл ли пароль.                                                                                                                                                         | O(1), вычислено при открытии.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `static GetEncryptionMode(path) -> EncryptionMode`    | Тот же режим без создания объекта `SqlceDatabase`.                                                                                                                                                                                            | Отдельный файловый дескриптор, читается только страница 0, закрывается сразу после чтения.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `ResolvedEncryptionMode() -> EncryptionMode`          | Алгоритм, фактически подтверждённый паролем при открытии.                                                                                                                                                                                     | `None` для незашифрованного файла.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `GetFormatVersion() -> FormatVersion`                 | Версия формата на фиксированном смещении страницы 0.                                                                                                                                                                                          | O(1)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `static GetFormatVersion(path) -> FormatVersion`      | Версия формата без создания объекта `SqlceDatabase`.                                                                                                                                                                                          | Читает только страницу 0.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `ExportDecrypted() -> vector<uint8_t>`                | Полное содержимое файла со снятым шифрованием. Каждая страница расшифрована; на странице 0 результата обнулены поля режима шифрования, verifier, key-param, provider-info и флага "был зашифрован", контрольная сумма страницы 0 пересчитана. | Если `ResolvedEncryptionMode() == None`, страницы возвращаются как есть, поля страницы 0 не модифицируются. O(P) по числу страниц, весь результат в памяти одновременно.                                                                                                                                                                                                                                                                                                                                                                                                       |
| `static VerifyPassword(path, password) -> bool`       | Проверка пароля на 4 алгоритмах без открытия файла как базы; останавливается на первом совпадении.                                                                                                                                            | Только страница 0 читается с диска, один раз, независимо от числа попыток.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `static VerifyPassword(path, password, mode) -> bool` | Проверка одного конкретного алгоритма.                                                                                                                                                                                                        | `EncryptionMode::None` недопустим - в этом случае бросается `UnsupportedEncryptionModeException`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |

## ColumnSchema ([sdf/application/ColumnSchema.hpp](../../core/include/sdf/application/ColumnSchema.hpp))

Неизменяемый снимок на момент вызова `TableSchema()`.

| Поле           | Описание                                                                                                                                                                                            |
|----------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `ordinal`      | Позиция колонки в таблице, с 1, по возрастанию ordinal каталога.                                                                                                                                    |
| `name`         | Имя колонки.                                                                                                                                                                                        |
| `typeName`     | `string_view`: `"int"`, `"nvarchar"`, `"ntext"`, `"image"`, `"uniqueidentifier"` и т. д.                                                                                                            |
| `declaredSize` | `optional<uint32_t>`: для NVarChar/NChar - число символов; для Binary/VarBinary - число байт; для Image - константа `0x3FFFFFFF`; для NText - константа `0x1FFFFFFF`; для прочих типов - `nullopt`. |
| `precision`    | `optional<uint8_t>`: фиксированные значения по типу или значения из каталога для Numeric, иначе `nullopt`.                                                                                          |
| `scale`        | `optional<uint8_t>`: фиксированные значения по типу или значения из каталога для Numeric, иначе `nullopt`.                                                                                          |

## LazyLob ([sdf/domain/LazyLob.hpp](../../core/include/sdf/domain/LazyLob.hpp))

Ленивая ссылка на LOB-значение (NText или Image) строки таблицы. Хранит источник чтения (страницы LOB-цепочки), не сами данные.

| Метод                               | Описание                                                                                                                                                                                                 |
|-------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `TotalLength() -> size_t`           | Полная длина значения в байтах.                                                                                                                                                                          |
| `IsText() -> bool`                  | `true` для NText, `false` для Image.                                                                                                                                                                     |
| `ReadBytes() -> vector<uint8_t>`    | Читает значение целиком как байты.                                                                                                                                                                       |
| `ReadText() -> string`              | Читает значение целиком как строку (после UTF-16LE- или Latin1-декодирования, в зависимости от флага сжатия значения); применимо только к NText.                                                         |
| `ReadChunks() -> LazyLobChunkRange` | Чтение по частям, без декодирования и без сборки в одну строку. Для не-inline значения - один элемент на страницу LOB-цепочки; для inline значения - один элемент (или ни одного, если значение пустое). |
| `LazyLobChunkRange::ChunkCount()`   | Возвращает общее число частей (зафиксировано при создании) без чтения их содержимого.                                                                                                                    |

| Параметр сложности      | Значение                                                                                                                                                     |
|-------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Сложность чтения        | O(L), L - длина значения в байтах.                                                                                                                           |
| Обращения к `PageBytes` | Для не-inline значения число обращений равно числу страниц LOB-цепочки (chunk = полезная нагрузка одной страницы LOB-страницы минус заголовок LOB-страницы). |

## Исключения

| Исключение                                                             | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `UnsupportedEncryptionModeException` (`sdf/domain/EncryptionMode.hpp`) | Запрошена деривация ключа для `EncryptionMode::None`, что не является алгоритмом деривации ключа. Единственный публичный путь к возникновению: `SqlceDatabase::VerifyPassword(path, password, EncryptionMode::None)`.                                                                                                                                                                                                                                                                           |
| `InvalidPasswordException` (`sdf/domain/EncryptionMode.hpp`)           | Пароль не подошёл ни к одному из 4 поддерживаемых алгоритмов при открытии файла, либо файл зашифрован, а пароль не передан. После успешного создания объекта `SqlceDatabase` это исключение более не может возникнуть ни у одного из его методов: резолюция алгоритма и проверка происходят единожды, в конструкторе. Не бросается, если пароль превышает максимальную длину (40 байт UTF-16LE) - в этом случае бросается обычное исключение превышения длины, а не `InvalidPasswordException`. |
| `InvalidSdfException` (`sdf/domain/InvalidSdfException.hpp`)           | Файл `.sdf` структурно некорректен: короче одной страницы; отсутствует или повреждена карта логических страниц (Map A / Map B); цепочка фрагментов строки, строки каталога или LOB-значения не резолвится до конца либо превышает внутренний лимит переходов по страницам продолжения. `what()` содержит текстовое описание конкретной причины.                                                                                                                                                 |

Пример использования: [sdf_dump](../../core/main.cpp)
