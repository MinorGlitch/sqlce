# Python API

Биндинг sqlce поверх [libsqlce](cpp.md) (pybind11). Только чтение `.sdf`-файлов (SQL Server Compact). Полная сигнатурная документация с семантикой каждого метода - в докстрингах нативного модуля: [_sqlce_native.pyi](../../python/sqlce/_sqlce_native.pyi).

## Установка

```text
pip install sqlce
```

## Пример

```python
from sqlce import SqlceDatabase

db = SqlceDatabase("file.sdf")
# или с паролем
db = SqlceDatabase("file.sdf", "password")

for name in db.list_tables():
    print(name)

for col in db.table_schema("MyTable"):
    print(col.ordinal, col.name, col.type_name, col.declared_size, col.precision, col.scale)

rows = db.read_table("MyTable")          # список dict-ов {имя колонки: значение}
for row in db.iterate_table("MyTable"):  # то же самое, но лениво
    print(row)
```

## SqlceDatabase

Доступ к `.sdf`-файлу только на чтение, методов записи нет. Открытие немедленно парсит системный каталог и резолвит страницы данных каждой таблицы; строки декодируются лениво, при обращении. Карта логических страниц и каталог читаются один раз и кешируются на всё время жизни объекта.

| Метод                                                                    | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Сложность / особенности                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|--------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `__init__(path)`                                                         | Открыть незашифрованный файл.                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | `InvalidPasswordError`, если файл защищён паролем (эта перегрузка пароль не принимает). O(P/1527 + K + T), где P - количество страниц в файле (количество страниц Map B растёт вместе с P, поскольку каждая страница Map B индексирует диапазон из 1527 логических идентификаторов, а каждая страница файла имеет логический идентификатор, включая страницы данных таблиц), K - количество heap-страниц системного каталога, а T - количество таблиц (по одной корневой странице на таблицу). |
| `__init__(path, password)`                                               | Открыть файл с паролем (не более 40 байт после кодирования UTF-16LE). Пароль проверяется по очереди с помощью verifier'а страницы 0 для всех 4 алгоритмов (`TRIPLE_DES_SHA1`, `AES128_SHA1`, `AES128_SHA256`, `AES256_SHA512`), пока не найдено совпадение. Сам файл хранит алгоритм шифрования, и он доступен через `GetEncryptionMode`, но конструктор на него не полагается. результат доступен через `resolved_encryption_mode()` и теоретически может отличаться от объявленного в файле режима. | Разрешение алгоритма: до 4 попыток, каждая - деривация ключа путём хеширования пароля плюс расшифрование одного блока verifier страницы 0. После этого разбор каталога - такой же, как в конструкторе без пароля: O(P/1527 + K + T) (подробности см. в описании той перегрузки).                                                                                                                                                                                                               |
| `list_tables() -> List[str]`                                             | Имена всех пользовательских таблиц в лексикографическом порядке.                                                                                                                                                                                                                                                                                                                                                                                                                                      | O(T), без обращения к файлу.                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `table_schema(table_name) -> List[ColumnSchema]`                         | Описания колонок в порядке возрастания ordinal.                                                                                                                                                                                                                                                                                                                                                                                                                                                       | O(C), без чтения страниц. `IndexError`, если таблицы с таким именем нет.                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `read_table(table_name) -> List[Row]`                                    | Читает и декодирует все строки таблицы разом в список; эквивалентно `list(self.iterate_table(table_name))`. LOB-колонки (NText, Image) в память не читаются - ячейка содержит объект `LazyLob`.                                                                                                                                                                                                                                                                                                       | O(R*C) по времени и памяти, весь результат в памяти одновременно.                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `iterate_table(table_name) -> TableRowIterator`                          | Ленивый построчный итератор: строки читаются и декодируются по одной по мере потребления итератора, без материализации всей таблицы в памяти.                                                                                                                                                                                                                                                                                                                                                         | `IndexError` бросается немедленно, при вызове метода; `InvalidSdfError` - лениво, во время итерации.                                                                                                                                                                                                                                                                                                                                                                                           |
| `row_count(table_name) -> int`                                           | Если корневая страница таблицы содержит распознаваемое поле кардинальности, значение читается напрямую из этого поля, без сканирования строк; иначе выполняется полный проход по `iterate_table` с подсчётом строк без декодирования значений колонок.                                                                                                                                                                                                                                                | O(1), если поле кардинальности распознано; O(R) иначе. Поле читается из файла при каждом вызове, не кешируется.                                                                                                                                                                                                                                                                                                                                                                                |
| `get_encryption_mode() -> EncryptionMode`                                | Режим, объявленный на странице 0, независимо от того, был ли дан и подошёл ли пароль.                                                                                                                                                                                                                                                                                                                                                                                                                 | O(1), вычислено при открытии.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `get_encryption_mode_from_file(path) -> EncryptionMode` (staticmethod)   | Тот же режим без создания объекта `SqlceDatabase`, без парсинга каталога и карты страниц.                                                                                                                                                                                                                                                                                                                                                                                                             | Отдельный файловый дескриптор, только страница 0, закрывается сразу после чтения.                                                                                                                                                                                                                                                                                                                                                                                                              |
| `resolved_encryption_mode() -> EncryptionMode`                           | Алгоритм, фактически подтверждённый паролем при открытии.                                                                                                                                                                                                                                                                                                                                                                                                                                             | `NONE` для незашифрованного файла.                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `get_format_version() -> FormatVersion`                                  | Версия формата на фиксированном смещении страницы 0.                                                                                                                                                                                                                                                                                                                                                                                                                                                  | O(1), вычислено конструктором.                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `get_format_version_from_file(path) -> FormatVersion` (staticmethod)     | То же поле без создания `SqlceDatabase`.                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Только страница 0.                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `export_decrypted() -> bytes`                                            | Полное содержимое файла со снятым шифрованием. Каждая страница расшифрована; на странице 0 результата обнулены поля режима шифрования, verifier, key-param, provider-info и флага "был зашифрован", контрольная сумма страницы 0 пересчитана. Если `resolved_encryption_mode() == NONE`, страницы возвращаются как есть. Требует, чтобы файл уже был успешно открыт конструктором с верным паролем.                                                                                                   | O(P) по числу страниц, весь результат в памяти одновременно.                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `verify_password(path, password) -> bool` (staticmethod)                 | Проверка пароля на 4 алгоритмах без открытия файла как базы, останавливается на первом совпадении; при несовпадении ни с одним - `False`, без исключения.                                                                                                                                                                                                                                                                                                                                             | Только страница 0 читается с диска, один раз, независимо от числа попыток.                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `verify_password_with_mode(path, password, mode) -> bool` (staticmethod) | Проверка одного конкретного алгоритма.                                                                                                                                                                                                                                                                                                                                                                                                                                                                | `mode=EncryptionMode.NONE` недопустим - бросает `UnsupportedEncryptionModeError`.                                                                                                                                                                                                                                                                                                                                                                                                              |

## ColumnSchema

Неизменяемый снимок на момент вызова `table_schema()`.

| Свойство        | Описание                                                                                                                                                                                              |
|-----------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `ordinal`       | Позиция колонки в таблице, с 1, по возрастанию ordinal каталога.                                                                                                                                      |
| `name`          | Имя колонки.                                                                                                                                                                                          |
| `type_name`     | `"int"`, `"nvarchar"`, `"ntext"`, `"image"`, `"uniqueidentifier"` и т. д.                                                                                                                             |
| `declared_size` | `Optional[int]`: NVarChar/NChar - число символов; Binary/VarBinary - число байт; Image - константа `0x3FFFFFFF`; NText - константа `0x1FFFFFFF`; прочие типы - `None`.                                |
| `precision`     | `Optional[int]`: фиксированные значения по типу (Bit=1/0, TinyInt=3, SmallInt=5, Int=10, BigInt=19, Real=24, Float=53, Money=19/4, DateTime=23/3) или значения из каталога для Numeric, иначе `None`. |
| `scale`         | `Optional[int]`: фиксированные значения по типу (Bit=1/0, TinyInt=3, SmallInt=5, Int=10, BigInt=19, Real=24, Float=53, Money=19/4, DateTime=23/3) или значения из каталога для Numeric, иначе `None`. |

## Типы

Значение колонки (`ColumnValue`) - обычный Python-объект.

| Python-тип          | Тип SQL Server Compact            | Описание                                                                 |
|---------------------|-----------------------------------|--------------------------------------------------------------------------|
| `None`              | NULL                              | NULL.                                                                    |
| `int`               | TinyInt / SmallInt / Int / BigInt | Целочисленное значение.                                                  |
| `float`             | Real / Float / Money              | Значение с плавающей точкой; Money декодируется соответствующим образом. |
| `bool`              | Bit                               | Логическое значение.                                                     |
| `str`               | NVarChar                          | Переменная длина, может быть Latin1-сжата.                               |
| `str`               | NChar                             | Фиксированная длина, всегда UTF-16LE.                                    |
| `bytes`             | Binary / VarBinary / RowVersion   | Бинарное значение.                                                       |
| `bytes`             | Любой нераспознанный тип          | Бинарное представление значения.                                         |
| `datetime.datetime` | DateTime                          | Из счётчика дней с 1900-01-01 и тиков 1/300 сек с полуночи.              |
| `decimal.Decimal`   | Numeric                           | Из precision/scale/знака и little-endian цифр каталога.                  |
| `uuid.UUID`         | UniqueIdentifier                  | 16 байт как `bytes_le`.                                                  |
| `LazyLob`           | NText / Image                     | Не читаются при декодировании строки.                                    |

| Тип строки                     | Описание                                                                            |
|--------------------------------|-------------------------------------------------------------------------------------|
| `Row = Dict[str, ColumnValue]` | Обычный словарь, порядок ключей соответствует возрастанию плотного ordinal колонки. |

### LazyLob

Ленивая ссылка на LOB-значение (NText или Image), возвращается вместо самого значения при чтении строки. Держит источник чтения (страницы LOB-цепочки), не данные.

| Метод                                   | Описание                                                                                                                         | Сложность / особенности                                                                                                                                                                  |
|-----------------------------------------|----------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `read() -> Union[str, bytes]`           | Читает значение целиком: `str` для NText (после UTF-16LE- или Latin1-декодирования по флагу сжатия значения), `bytes` для Image. | O(L), L - длина значения в байтах; для не-inline значения число обращений к постраничному кешу равно числу страниц LOB-цепочки.                                                          |
| `read_chunks() -> LazyLobChunkIterator` | Чтение по частям, без декодирования и без сборки в единую строку; части читаются лениво, по одной на вызов `__next__()`.         | Для не-inline значения - один элемент на страницу LOB-цепочки; для inline - один элемент (или ни одного для пустого значения). O(L) суммарно, O(1) на часть, O(1) для `len()` итератора. |

### TableRowIterator

Возвращается `iterate_table()`. Держит ссылку на объект `SqlceDatabase` - тот не уничтожается, пока итератор жив.

| Операция / характеристика  | Описание                                                                                                                                                                                                                                                                                 |
|----------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `__next__()`               | Ищет и декодирует следующую строку, начиная поиск со слота сразу после текущей позиции; сканирует слоты текущей страницы данных, при исчерпании переходит на следующую страницу данных таблицы; фрагментированную по нескольким страницам строку собирает по цепочке слотов продолжения. |
| Сложность поиска           | O(P) в худшем случае (P - число несканированных страниц данных до следующей строки).                                                                                                                                                                                                     |
| Амортизированная сложность | O(1) амортизированно при плотной упаковке строк.                                                                                                                                                                                                                                         |
| Декодирование строки       | O(C) на декодирование C колонок строки.                                                                                                                                                                                                                                                  |
| Завершение                 | Бросает `StopIteration`.                                                                                                                                                                                                                                                                 |
| Ошибка структуры           | Бросает `InvalidSdfError`, если цепочка слотов продолжения строки не резолвится до конца либо превышает внутренний лимит переходов.                                                                                                                                                      |

## Исключения

| Исключение                       | Базовый класс | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|----------------------------------|---------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `UnsupportedEncryptionModeError` | `ValueError`  | Деривация ключа запрошена для `EncryptionMode.NONE`, что не является алгоритмом деривации ключа. Единственный публичный путь: `verify_password_with_mode(..., mode=EncryptionMode.NONE)`.                                                                                                                                                                                                                                                                                                                                                           |
| `InvalidPasswordError`           | `ValueError`  | Пароль не подошёл ни к одному из 4 алгоритмов (`TRIPLE_DES_SHA1`, `AES128_SHA1`, `AES128_SHA256`, `AES256_SHA512`) при открытии файла, либо файл зашифрован, а пароль не передан. После успешного создания объекта `SqlceDatabase` это исключение более не может возникнуть ни у одного из его методов: резолюция алгоритма и проверка происходят единожды, в конструкторе, результат кешируется на всё время жизни объекта. Не бросается, если пароль превышает 40 байт после кодирования UTF-16LE - в этом случае бросается обычный `ValueError`. |
| `InvalidSdfError`                | `ValueError`  | Файл `.sdf` структурно некорректен: короче одной страницы; отсутствует или повреждена карта логических страниц (Map A / Map B); цепочка фрагментов строки, строки каталога или LOB-значения не резолвится до конца либо превышает внутренний лимит переходов по страницам продолжения. `str(error)` содержит текстовое описание конкретной причины.                                                                                                                                                                                                 |
